# 刮个爽

一个纯娱乐的多人刮刮乐网页游戏。玩家输入昵称即可获得自动生成的玩家 ID，无需密码注册。

## 功能

### 彩票类
- 🏮 喜相逢 — 刮 30 格，出现"喜"或"囍"即中奖
- 7️⃣ 数字 7 — 刮 20 个号码，含 7 即中
- 🧧 金玉满堂 — 九宫格集齐 3 个相同宝物
- ⚡ 好运十倍 — 匹配幸运数字，倍数最高 ×10
- 🐟 锦鲤驾到 — 找到锦鲤中奖，双锦鲤超级大奖
- 🃏 百家乐 — 庄家发牌比大小
- 🔴 双色球 — 机选 6+1，模拟开奖

### 街机类
- 🧠 24点挑战 — 庄家发 4 张牌，输入算式凑 24
- 🪙 推币机 — 瞄准投币，推板推动币堆
- 🕹️ 抓娃娃机 — 移动机械爪抓取娃娃
- 🍒 水果机 — 三列转轮旋转匹配
- 🔮 弹珠台 — 弹珠落入奖池
- 🎡 幸运转盘 — 旋转转盘碰运气

### 系统功能
- SQLite 持久化玩家等级、爽币、图鉴和中奖记录
- 服务器生成与结算票据，避免前端篡改奖金
- 免注册玩家身份与全服排行榜（分页）
- 管理员后台：可配置中奖率与奖级
- 反脚本机制：购票冷却、每日上限、IP 限流
- 多级大奖：最高可达 100 万爽币
- 手机和桌面响应式界面

## 启动

需要 Python 3.9 或更高版本，无第三方依赖。

```bash
python3 app.py
```

默认监听 `0.0.0.0:8089`。可通过环境变量修改：

```bash
HOST=127.0.0.1 PORT=9000 SCRATCH_DB=/path/game.db python3 app.py
```

## 管理员后台

点击右上角 ⚙ 图标进入管理员后台。

默认凭据：
- 用户名: `ysz`
- 密码: `PASSWORD_REMOVED`

管理员可实时调整中奖概率、保底机制强度等参数。
