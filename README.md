# 刮个爽

一个纯娱乐的多人刮刮乐网页游戏。玩家输入昵称即可获得自动生成的玩家 ID，无需密码注册。

## 功能

- 喜相逢、数字 7、金玉满堂、好运十倍、锦鲤驾到
- SQLite 持久化玩家等级、爽币、图鉴和中奖记录
- 服务器生成与结算票据，避免前端篡改奖金
- 免注册玩家身份与全服排行榜
- 手机和桌面响应式界面

## 启动

需要 Python 3.9 或更高版本，无第三方依赖。

```bash
python3 app.py
```

默认监听 `0.0.0.0:8089`。可通过环境变量修改：

```bash
HOST=127.0.0.1 PORT=9000 SCRATCH_DB=/path/game.db python3 app.py
```

## 数据

数据库默认保存在 `data/scratch_game.db`，该目录已被 `.gitignore` 排除。

> 本项目仅为娱乐模拟游戏，不含充值、提现或兑奖功能。
